# LIVE HAND v2.0 — Two hands + depth

## Что нового
- До двух рук одновременно.
- 21 landmark на каждую руку.
- Передаётся координата глубины Z, чтобы сгибание пальцев не оставалось плоским.
- Roblox рисует две локальные 3D-кисти: суставы, сегменты пальцев и объёмную ладонь.
- Правая и левая руки имеют разные цвета для отладки.

## Обновить существующий Render-сервис
Не создавай новый сервис.
1. В GitHub открой существующий репозиторий `live-hand`.
2. Замени `server.js` и `index.html` файлами из этого архива.
3. Замени Roblox Lua-скрипт на `LIVE_HAND_v2_Delta.lua`.
4. Commit changes. Render автоматически начнёт новый deploy.
5. Дождись статуса Live.
6. Открой https://live-hand.onrender.com и обнови страницу без кэша, затем нажми «Запустить трекер».
7. Перезапусти Lua-скрипт в Delta.

## Важно
- Это всё ещё визуальная локальная модель из 3D-частей Roblox, не полноценная скульптурная рука.
- MediaPipe Z — относительная оценка глубины, а не точное измерение расстояния. При слабом освещении и перекрытии пальцев глубина может плавать.
- Для двух рук нужно держать обе кисти в кадре.
- Если Render показывает Live, но трекер не запускается, обнови страницу и проверь `/health`.
- Вторая версия использует новый формат `/pose` с массивом `hands`; старый Lua v1 несовместим с новым форматом. Обнови обе стороны.
