# LIVE HAND v1.0

## Что это
Прототип: браузер распознаёт одну руку через MediaPipe и отправляет 21 точку на сервер. Roblox-скрипт получает точки и рисует локальный скелет кисти перед персонажем.

## Развёртывание на Render через GitHub (телефон)
1. Создай новый публичный GitHub-репозиторий `live-hand`.
2. Загрузи в корень репозитория три файла: `server.js`, `index.html`, `package.json`.
3. На Render выбери New + -> Web Service и подключи этот репозиторий.
4. Runtime: Node. Build Command: `npm install` (или пусто). Start Command: `npm start`.
5. После статуса Live открой `https://ИМЯ-СЕРВИСА.onrender.com/` в Chrome.
6. Нажми «Запустить трекер» и разреши доступ к камере.

## Roblox
1. Открой `roblox.lua` и замени `https://YOUR-SERVICE.onrender.com` на адрес Render.
2. Открой Roblox и запусти скрипт через Delta.
3. Держи страницу трекера открытой в другом окне.

## Проверка
Открой `https://ИМЯ-СЕРВИСА.onrender.com/health` — должен вернуться JSON с `ok:true`.

## Ограничения первой версии
- Это визуальный скелет кисти, не полноценная реалистичная 3D-модель.
- Нужна поддержка HTTP request в Delta.
- Бесплатный Render может засыпать; первый запрос после сна будет медленным.
- Roblox и Chrome должны работать одновременно в нескольких окнах; Android может ограничивать камеру в фоне.
- Данные передаются через публичный тестовый endpoint без авторизации. Не используй его для чувствительных данных.
